# MATLAB code

- Must run in both MATLAB and Octave. Avoid Octave-only syntax (`#` comments, `!=`,
  `endif`, `x++`) and double-quoted strings (a `string` in MATLAB, a `char` in Octave);
  use single quotes.
- File names must be valid identifiers: a letter first, then letters, digits, underscores.
